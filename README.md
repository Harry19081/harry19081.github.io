# harry19081.github.io

Personal site, served by GitHub Pages at **https://harry19081.github.io**.

React 19 + Vite + TypeScript. No UI framework — hand-rolled CSS with light/dark themes.

## Develop

```sh
npm install
npm run dev
```

## Deploy

Push to `main`. The [Deploy site workflow](.github/workflows/deploy.yml) builds the app and
publishes `dist/` to GitHub Pages (~1 minute; progress under the **Actions** tab).
